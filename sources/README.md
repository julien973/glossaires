# 📁 sources/ — romans sources de tous les glossaires

Ce dossier contient les romans (PDF ou EPUB) de **tous les glossaires du site** — pas seulement un seul roman. Chaque glossaire du site correspond à un roman, et la source de chaque roman vit ici : les romans actuels comme ceux ajoutés plus tard.

## Contenu actuel

- `1-497.pdf` — roman du glossaire cyberpunk 《我的赛博朋克模拟器》 (chapitres 1 à 497).

## Déposer un roman (nouveau glossaire ou suite d'un roman)

1. Ouvre ce dossier `sources/` sur GitHub.
2. Clique sur **Add file → Upload files**.
3. Glisse le fichier du roman (PDF ou EPUB).
4. **Commit changes**.

Pas besoin de renommer, le fichier reste tel quel. Si un roman est en plusieurs fichiers, un sous-dossier par roman est préférable (ex. `sources/nom-du-roman/`).

## Notes

- ⚠️ Le dépôt est public : chaque fichier est accessible à toute personne qui connaît l'URL exacte (les moteurs de recherche ne l'indexent pas : robots.txt).
- Usage : identification d'un nouveau roman et vérification des chapitres de chaque glossaire, surtout au-delà des pages officielles.
- L'identification d'un roman (titre, raws, traductions) est faite automatiquement par Vibe lors de la création de son glossaire.
