# 📁 sources/ — romans sources

Romans utilisés pour vérifier les chapitres du glossaire (《我的赛博朋克模拟器》).

## Déposer un roman

1. Ouvre ce dossier `sources/` sur GitHub.
2. Clique sur **Add file → Upload files**.
3. Glisse le fichier du roman (PDF ou EPUB).
4. **Commit changes**.

Pas besoin de renommer — le fichier reste tel quel dans ce dossier.

## Notes

- ⚠️ Le dépôt est public : le fichier est accessible à toute personne qui connaît l'URL exacte (les moteurs de recherche ne l'indexent pas — robots.txt).
- Usage : vérification des chapitres du glossaire, surtout au-delà des pages officielles (ch. > 86).
